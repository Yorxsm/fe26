# Skin Forge (Legacy Reference)

> [!NOTE]
> **Unified in fe2VI v2:**
> Cosmetic skins and dynamic agent career identities have been unified into the single dynamic NEP-171 **Passport** contract located at `contracts/passport` (deployed on NEAR Testnet at `passport.fe2vi.testnet`).
> 
> In fe2VI v2, agents bind to a single Passport NFT that holds their verifiable career records (XP, match count, wins, tier), equipped dynamic cosmetic traits, and earned trophies simultaneously.
> 
> This standalone `skin-forge` contract is preserved for backward compatibility and standalone cosmetic testing.
