# Assets

Reference plates live in `docs/concept/` (`city-concept.jpg`, `agent-sheet.jpg`, `fe2vi-logo-400.png`, `fe2vi-x-banner-1500x500.png`). They set the station layout, the ingot roles, and the mark. The meshes are not traced from those plates.

The station, rooms, and agents under `apps/web/public/models/` are original meshes. They are produced by `tools/blender/build_station.py` and then meshopt-compressed. They are not traced from a character pack and they are not imported from the CC0 kits below. The mark at `apps/web/public/fe2vi-logo-400.png` is also `app/icon.png` and the Open Graph image.

Rebuild from the repo root:

```sh
blender --background --python tools/blender/build_station.py
npx --yes @gltf-transform/cli@4.1.1 meshopt apps/web/public/models/station.glb apps/web/public/models/station.glb
npx --yes @gltf-transform/cli@4.1.1 meshopt apps/web/public/models/agent.glb apps/web/public/models/agent.glb
```

Blender 4.0 builds Z-up. The exporter writes glTF Y-up. `layout.json` is in glTF meters. Room markers inside `station.glb` are empties named `marker.<district-id>`.

| File | Bytes | What it is |
| --- | ---: | --- |
| `apps/web/public/models/station.glb` | 250996 | Octagonal station. The vault has a round door, gold piles, coins, cameras, and red tripwires |
| `apps/web/public/models/agent.glb` | 53576 | Beveled ingot with stubby legs, a hexagonal core, and the catalog parts below |
| `apps/web/public/models/layout.json` |  | Room ids and glTF positions for the scene |

Both GLBs use `EXT_meshopt_compression` (plus `KHR_mesh_quantization` and `KHR_materials_emissive_strength`). Draco is not used: this Blender build has no Draco encoder, and a CDN decoder is the wrong trade. The scene loads them with three's `MeshoptDecoder`.

The world is lit by a CC0 HDRI for reflections only. The sky is a gradient in the page, not the HDRI background. Steel and grate images are generated by `tools/blender/make_textures.py`.

The agent clips are `idle`, `walk`, and `celebrate` on `bone.root`, `bone.body`, `bone.leg.L`, and `bone.leg.R`. The walk swing is bone-local. Confirm the axis when the city plays the clip.

Trait indexes match `crates/fe2vi-core/src/skin.rs`. The scene shows one face and the parts for the equipped skin. A default skin hides every `hat.*` and `acc.*` the seed did not pick. Body color is the `Body` material, not a separate mesh. Trails are particles, not geometry.

| Index | Hat node | Role outfit | Accessory nodes | Face node |
| --- | --- | --- | --- | --- |
| 0 | none | safecracker, uses hat.1 | none | `face.0` neutral core |
| 1 | `hat.1` beanie | trader, visor plus headset | `acc.1.L`, `acc.1.R`, `acc.1.band` | `face.1` |

| 5 | `hat.5`, `hat.5.tip` antenna | scout, goggles plus hip kit | `acc.5` bolt |  |

The hip kit is a side satchel. The body stays a boxy ingot.

`apps/web/components/CityMap.tsx` loads both files with drei `useGLTF` and three-stdlib's meshopt decoder. Draco stays off so the page does not fetch a decoder.

Sound is synthesized in `apps/web/lib/audio.ts`. There is no sample file. A district bed is noise plus a sine, placed on a panner at that room, so the room near the camera is louder. The title theme is a short sine line. Clicks, hovers, and the heist, breach, trade, rank, quest, and forge stings are oscillators. Playback starts from ENTER AS SPECTATOR, or from Unmute if the spectator skipped. Mute, volume, and Quiet are stored in `localStorage` under `fe2vi.audio.v1`. Quiet and reduced motion duck the stings.

Kenney's CC0 kits stay vendored and unused as characters, so the silhouette stays the ingot.

## Fonts

UI text loads through `next/font/google` (`Unbounded`, `Manrope`, `JetBrains Mono`). Next downloads the subsets at build time and serves them from this site. The browser does not call Google.

Unbounded is the display face: titles, the HUD brand, room signs, and intro captions. Manrope is body and HUD copy. JetBrains Mono is only for numbers, account addresses, pins, and leaderboards.

drei `Text` cannot read the woff2 subsets Next emits. In-world signs use the same families as static TrueType files, instantiated from the official variable fonts and served from `apps/web/public/fonts/`. `apps/web/lib/fonts.ts` points at those files. Room signs use `Unbounded-Bold.ttf`.
