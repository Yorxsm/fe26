# Assets

The city map's rooms, corridors, and agents are original primitives in `apps/web/components/CityMap.tsx`. The agent is a rounded ingot with stubby legs and a square core panel. Those meshes are not imported from a character pack.

Kenney's CC0 kits are vendored for the record and for later set dressing. The map does not instance them as characters.
